2.0.015 March 2026

A full rewrite

Half the memory, twice the throughput, and a plugin API we're finally willing to commit to long term.

Added
  • Plugin API with a stable, versioned surface
  • Multi-window sessions that survive a restart
  • Native arm64 builds for Apple silicon and Linux
Changed
  • Rendering moved off the main thread — input stays responsive under load
  • Configuration is now TOML; existing JSON auto-migrates on first run
Fixed
  • Memory growth during sessions longer than about six hours
  • Focus loss when reattaching an external display
Breaking

The halcyon.json format is removed. Run halcyon migrate once — it rewrites your config in place and keeps a backup.
