Re-skinning is one paste

Every template reads the same nine CSS variables. The pack ships 50 hand-tuned dark palettes — copy a file from themes/, paste it over the template's :root block, done. No config, no preprocessor.

  --bg:#1D1E20; --surface:#242528; --hair:#3A3B3D;
  --ink:#E9EAEC; --mute:#A0A4AB; --faint:#6E7176;
  --accent:#C9CFD6; --accent-2:#F7F8F9; --accent-dim:#575A5E;
}
